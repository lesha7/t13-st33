## Обзор

Система управления пользователями - это настольное приложение WPF (.NET 8.0), которое обеспечивает безопасную аутентификацию пользователей и возможности управления. Система поддерживает контроль доступа на основе ролей с тремя типами пользователей: Руководитель, Администратор и Клиент.

### Ключевые функции
- Безопасная аутентификация пользователей с отслеживанием попыток входа
- Контроль доступа на основе ролей
- Управление учетными записями пользователей (добавление, редактирование, просмотр пользователей)
- Функция изменения пароля для клиентов
- Блокировка аккаунта после неудачных попыток входа
- Автоматическая деактивация аккаунтов неактивных пользователей
- Интеграция с базой данных PostgreSQL

### Технологический стек
- **Фреймворк**: .NET 8.0 WPF
- **База данных**: PostgreSQL
- **ORM**: Npgsql (PostgreSQL .NET коннектор)
- **UI Фреймворк**: WPF с XAML

## Схема базы данных

### Таблица Users
```sql
CREATE TABLE "Users" (
    Id SERIAL PRIMARY KEY,
    Surname VARCHAR(100) NOT NULL,
    Name VARCHAR(100) NOT NULL,
    Othcestvo VARCHAR(100) NOT NULL,
    Role VARCHAR(100) NOT NULL,
    Login VARCHAR(100) NOT NULL,
    Password VARCHAR(100) NOT NULL,
    Count INT NOT NULL,
    Active BIT NOT NULL,
    Date DATE NOT NULL
);
```

#### Описание полей
- **Id**: Уникальный идентификатор пользователя (автоинкремент)
- **Surname**: Фамилия пользователя
- **Name**: Имя пользователя  
- **Othcestvo**: Отчество пользователя
- **Role**: Роль пользователя (1=Руководитель, 2=Администратор, 3=Клиент)
- **Login**: Уникальное имя пользователя для входа
- **Password**: Пароль пользователя (хранится в открытом тексте)
- **Count**: Счетчик неудачных попыток входа
- **Active**: Статус аккаунта (0=Активный, 1=Заблокирован)
- **Date**: Дата последнего входа

### Подключение к базе данных
```
Хост: localhost
Имя пользователя: postgres
Пароль: root
База данных: postgres
```

### Класс MainWindow

#### Конструктор


**Использование**: Точка входа для аутентификации пользователей.

#### Метод Button1_Click
```csharp
private void Button1_Click(object sender, RoutedEventArgs e)
```
**Описание**: Обрабатывает аутентификацию пользователя с комплексными проверками безопасности.

**Поток аутентификации**:
1. Проверяет поля ввода
2. Проверяет существование пользователя в базе данных
3. Проверяет, что аккаунт не заблокирован
4. Проверяет пароль
5. Проверяет активность аккаунта (блокирует если неактивен > 1 месяца)
6. Обновляет счетчик попыток входа
7. Перенаправляет на соответствующий интерфейс в зависимости от роли

**Функции безопасности**:
- Блокировка аккаунта после 3 неудачных попыток
- Автоматическая блокировка аккаунтов неактивных > 1 месяца
- Отслеживание неудачных попыток входа
- Перенаправление на основе ролей

**Пример использования**:

## Обработка ошибок

### Обрабатываемые типы исключений
1. **NpgsqlException**: Ошибки подключения к базе данных и запросов
2. **General Exception**: Все остальные непредвиденные ошибки

### Сообщения об ошибках
- **Неверные учетные данные**: "Неверный логин или пароль"
- **Аккаунт заблокирован**: "Вы заблокированы. Обратитесь к администратору"
- **Неактивный аккаунт**: "Аккаунт заблокирован из-за долгого отсутствия"
- **Неудачный вход**: "Неверный пароль. Осталось попыток: {попытки}"
- **Пропущенные поля**: "Поля обязательны для заполнения"
- **Ошибка базы данных**: "Ошибка БД: {сообщение об ошибке}"

### Лучшие практики обработки ошибок
```csharp
try
{
    // Операции с базой данных
```

## Функции безопасности

### Безопасность аутентификации
1. **Отслеживание попыток входа**: Максимум 3 неудачные попытки до блокировки аккаунта
2. **Блокировка аккаунта**: Автоматическая блокировка после неудачных попыток
3. **Тайм-аут сессии**: Аккаунты блокируются после 1 месяца неактивности
4. **Проверка пароля**: Требуется для всех операций

### Ограничения безопасности
⚠️ **Важные заметки о безопасности**:
- Пароли хранятся в открытом тексте (следует использовать хеширование)
- Нет требований к сложности пароля
- Нет управления сессиями
- Жестко закодированные учетные данные базы данных
- TextBox используется для ввода пароля (следует использовать PasswordBox)

### Рекомендуемые улучшения безопасности
1. Реализовать хеширование паролей (BCrypt/Argon2)
2. Добавить требования к сложности пароля
3. Использовать PasswordBox для ввода паролей
4. Реализовать правильное управление сессиями
5. Использовать файлы конфигурации для подключений к базе данных
6. Добавить проверку и санитизацию ввода
7. Реализовать аудит логирования
