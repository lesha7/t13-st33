# Руководство пользователя

## Введение

Добро пожаловать в систему управления пользователями! Это приложение предназначено для безопасного управления учетными записями пользователей с разными уровнями доступа.

## Запуск приложения

1. Запустите файл `demo2.exe`
2. Откроется главное окно входа в систему

## Вход в систему

### Шаг 1: Ввод данных
1. В поле "Введите логин" укажите ваш логин
2. В поле "Введите пароль" введите ваш пароль
3. Нажмите кнопку "Войти"

### Возможные ошибки при входе:

#### "Поля обязательны для заполнения"
- **Причина**: Не заполнен логин или пароль
- **Решение**: Заполните все обязательные поля

#### "Неверный логин или пароль"
- **Причина**: Указан несуществующий логин
- **Решение**: Проверьте правильность написания логина

#### "Неверный пароль. Осталось попыток: X"
- **Причина**: Введен неправильный пароль
- **Решение**: Проверьте правильность пароля
- **Внимание**: После 3 неудачных попыток аккаунт будет заблокирован

#### "Вы заблокированы. Обратитесь к администратору"
- **Причина**: Аккаунт заблокирован после превышения лимита попыток входа
- **Решение**: Обратитесь к администратору системы

#### "Аккаунт заблокирован из-за долгого отсутствия"
- **Причина**: Аккаунт не использовался более месяца
- **Решение**: Обратитесь к администратору для разблокировки

## Работа с разными ролями

### Руководитель (Роль 1)

После успешного входа вы увидите сообщение: "Добро пожаловать как руководитель [Фамилия]"

**Возможности:**
- Просмотр статуса авторизации
- Доступ к информационному окну

**Интерфейс:**
- Простое окно с подтверждением статуса: "Вы авторизовались как руководитель"

### Администратор (Роль 2)

После успешного входа вы увидите сообщение: "Добро пожаловать как администратор [Фамилия]"

#### Основные функции:

##### Добавление нового пользователя:

1. **Заполните обязательные поля:**
   - "Имя нового пользователя" - логин для входа в систему
   - "Введите пароль" - пароль для нового пользователя
   - "Фамилия" - фамилия пользователя
   - "Имя" - имя пользователя
   - "Отчество" - отчество пользователя (необязательно)

2. **Выберите роль пользователя:**
   - Руководитель (1)
   - Администратор (2)
   - Клиент (3)

3. **Нажмите кнопку "Добавить"**

**Возможные ошибки:**
- "Заполните все обязательные поля!" - не все поля заполнены
- При успехе: "Пользователь добавлен!"

##### Редактирование пользователей:

1. **Просмотр всех пользователей:**
   - В нижней части окна отображается таблица со всеми пользователями
   - Столбцы: ID, Фамилия, Имя, Отчество, Роль, Логин, Пароль, Кол-во вводов, Активность, Дата входа

2. **Редактирование данных:**
   - Дважды щелкните по ячейке в таблице для редактирования
   - Измените необходимые данные
   - Нажмите кнопку "Сохранить изменения"

**Результат:**
- При успехе: "Изменения сохранены!"

### Клиент (Роль 3)

После успешного входа вы увидите сообщение: "Добро пожаловать как клиент [Фамилия]"

#### Обязательная смена пароля:

Клиенты должны сменить пароль при первом входе.

##### Шаги смены пароля:

1. **Заполните все поля:**
   - "Старый пароль" - ваш текущий пароль
   - "Новый пароль" - желаемый новый пароль
   - "Подтвердите пароль" - повторите новый пароль

2. **Нажмите кнопку "Изменить пароль"**

**Возможные ошибки:**

#### "Все поля обязательны для заполнения!"
- **Причина**: Не заполнены все обязательные поля
- **Решение**: Заполните все поля формы

#### "Новые пароли не совпадают!"
- **Причина**: Пароли в полях "Новый пароль" и "Подтвердите пароль" не одинаковые
- **Решение**: Убедитесь, что пароли написаны одинаково

#### "Старый пароль неверен!"
- **Причина**: Неправильно указан текущий пароль
- **Решение**: Проверьте правильность ввода старого пароля

#### "Пароль успешно изменен!"
- **Результат**: Пароль изменен, происходит возврат к главному окну

## Рекомендации по безопасности

### Создание надежного пароля:
- Используйте не менее 8 символов
- Включайте заглавные и строчные буквы
- Добавляйте цифры и специальные символы
- Не используйте словарные слова
- Не используйте личную информацию

### Правила работы с аккаунтом:
- Не сообщайте пароль другим пользователям
- Регулярно входите в систему (не реже раза в месяц)
- Немедленно сообщайте администратору о подозрительной активности
- Выходите из системы после завершения работы

## Решение проблем

### Забыли пароль?
Обратитесь к администратору системы для сброса пароля.

### Аккаунт заблокирован?
Обратитесь к администратору системы для разблокировки.

### Ошибки подключения к базе данных?
Сообщите администратору о технической проблеме.

### Приложение не запускается?
Убедитесь, что:
- Установлен .NET Framework 4.7.2 или выше
- PostgreSQL сервер запущен и доступен
- У вас есть права на выполнение приложения

## Горячие клавиши

- **Enter** - подтверждение действия (аналог нажатия кнопки)
- **Tab** - переход между полями ввода
- **Esc** - закрытие текущего окна (где применимо)

## Техническая поддержка

При возникновении проблем обращайтесь к администратору системы или в службу технической поддержки.

**Информация для службы поддержки:**
- Версия приложения
- Текст сообщения об ошибке
- Действия, которые привели к ошибке
- Ваша роль в системе
- Время возникновения проблемы

## Часто задаваемые вопросы

### В: Могу ли я изменить свой логин?
О: Нет, логин может изменить только администратор системы.

### В: Как часто нужно менять пароль?
О: Рекомендуется менять пароль каждые 3-6 месяцев.

### В: Что делать, если я случайно изменил чужие данные?
О: Немедленно сообщите администратору о случайном изменении.

### В: Могу ли я видеть пароли других пользователей?
О: Администраторы могут видеть пароли в таблице, но это не рекомендуется по соображениям безопасности.

### В: Как выйти из системы?
О: Просто закройте окно приложения.
