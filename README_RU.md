# Система управления пользователями

## Описание
Приложение WPF для управления пользователями с ролевой моделью доступа и системой аутентификации. Система поддерживает трех типов пользователей: руководитель, администратор и клиент.

## Возможности системы

### Аутентификация
- Вход в систему по логину и паролю
- Защита от брутфорс атак (блокировка после 3 неудачных попыток)
- Автоматическая блокировка неактивных аккаунтов (более месяца)
- Сброс счетчика неудачных попыток при успешном входе

### Роли пользователей

#### 1. Руководитель (роль 1)
- Просмотр информации о статусе авторизации
- Доступ к Window1

#### 2. Администратор (роль 2)
- Добавление новых пользователей
- Редактирование данных существующих пользователей
- Управление ролями пользователей
- Просмотр всех пользователей в табличном виде
- Доступ к Window2

#### 3. Клиент (роль 3)
- Обязательное изменение пароля при первом входе
- Доступ к UpdatePass окну

## База данных

### Таблица Users
```sql
CREATE TABLE "Users" (
    id SERIAL PRIMARY KEY,
    surname VARCHAR(100),
    name VARCHAR(100),
    othcestvo VARCHAR(100),
    role INTEGER,
    login VARCHAR(50) UNIQUE,
    password VARCHAR(100),
    count INTEGER DEFAULT 0,
    active BIT(1) DEFAULT B'0',
    date TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### Поля таблицы:
- `id` - Уникальный идентификатор пользователя
- `surname` - Фамилия
- `name` - Имя
- `othcestvo` - Отчество
- `role` - Роль пользователя (1-руководитель, 2-администратор, 3-клиент)
- `login` - Логин для входа
- `password` - Пароль
- `count` - Количество неудачных попыток входа
- `active` - Статус активности (0-активен, 1-заблокирован)
- `date` - Дата последнего входа

## Требования к системе

### Программное обеспечение
- .NET Framework 4.7.2 или выше
- PostgreSQL сервер
- Npgsql драйвер для PostgreSQL

### Настройка подключения к БД
```csharp
string connString = "Host=localhost;Username=postgres;Password=root;Database=postgres";
```

## Безопасность

### Механизмы защиты:
1. **Защита от брутфорс атак**: блокировка аккаунта после 3 неудачных попыток
2. **Автоматическая деактивация**: блокировка неактивных более месяца аккаунтов
3. **Ролевая модель**: разграничение доступа по ролям
4. **Обязательная смена пароля**: для клиентов при первом входе

### Сообщения об ошибках:
- "Поля обязательны для заполнения"
- "Неверный логин или пароль"
- "Вы заблокированы. Обратитесь к администратору"
- "Неверный пароль. Осталось попыток: X"
- "Аккаунт заблокирован из-за долгого отсутствия"

## Интерфейс пользователя

### Главное окно (MainWindow)
- Поле ввода логина
- Поле ввода пароля
- Кнопка "Войти"

### Окно администратора (Window2)

- Поле старого пароля

1. Установите PostgreSQL сервер
2. Создайте базу данных и таблицу Users
3. Настройте строку подключения в коде
4. Скомпилируйте и запустите приложение
